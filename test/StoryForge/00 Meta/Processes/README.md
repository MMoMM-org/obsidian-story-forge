# Processes / Flows

Short how-to and workflow documents for recurring routines in the vault — the *how*, not the *what* (facts live in Canon/Bible). Every routine with more than one step, or that is encoded in several places, gets a document here as the source of truth.

- [[Create-New-Book]] — the scaffold of a new volume: folders, book note, Longform draft.
- [[Snowflake-Process]] — the order in which the plot documents (❄️🔍🎬📋) are worked through.
- [[Create-Scene]] — the transition beat → prose: create a scene and wire it up (`beat`/`order`/POV …).
- [[Scene-Status]] — the status stages of a scene + how to set/advance them.
- [[Create-Canon-Entity]] — character/location/object/lore as a canonical note (read-only, as a proposal).
- [[Continuity-Check]] — check a draft against the canon (read-only) before a scene goes to `done`.
- [[Git-Backup-Flow]] — obsidian-git auto-backup vs. `claude/` branch work in the shared worktree.
- [[Rework-Flow]] — revise a version: style analysis → plan → rewrite into V2 → check.
