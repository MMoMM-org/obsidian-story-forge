# Prozesse / Flows

Kurze How-to- und Workflow-Dokumente für wiederkehrende Abläufe im Vault — das *Wie*, nicht das *Was* (Fakten stehen in Canon/Bibel). Jeder Ablauf, der mehr als einen Handgriff hat oder an mehreren Stellen kodiert ist, bekommt hier ein Dokument als Quelle der Wahrheit.

- [[Neues-Buch-Anlegen]] — das Gerüst eines neuen Bandes: Ordner, Buch-Notiz, Longform-Draft.
- [[Snowflake-Prozess]] — in welcher Reihenfolge die Plot-Dokumente (❄️🔍🎬📋) bearbeitet werden.
- [[Szene-Anlegen]] — der Übergang Beat → Prosa: Szene anlegen und verdrahten (`beat`/`order`/POV …).
- [[Szenen-Status]] — die Status-Stufen einer Szene + wie man sie setzt/weiterschaltet.
- [[Canon-Entitaet-Anlegen]] — Figur/Ort/Objekt/Lore als kanonische Notiz (read-only, als Vorschlag).
- [[Continuity-Check]] — Entwurf gegen den Canon prüfen (read-only), bevor eine Szene auf `done` geht.
- [[Git-Backup-Flow]] — obsidian-git-Auto-Backup vs. `claude/`-Branch-Arbeit im geteilten Arbeitsbaum.
- [[Rework-Ablauf]] — eine Fassung überarbeiten: Stilanalyse → Plan → Rewrite in V2 → Check.
