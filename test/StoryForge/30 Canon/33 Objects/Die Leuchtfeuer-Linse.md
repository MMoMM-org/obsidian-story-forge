# Die Leuchtfeuer-Linse

## Overview

Eine handgeschliffene Kristalllinse im Herzen des [[Leuchtturm von Mondhafen]]. Durch sie scheint [[Das Mondfeuer]] und wird zum silbernen Strahl, der die Bucht schützt. Gehütet von [[Tobias Ferro]].

## Description

Faustgroß, von unzähligen Facetten durchzogen, im Innern ein Funke, der nie ganz erlischt — solange man ihn nährt.

## Significance

Ohne die Linse ist der Turm nur ein Turm. Sie ist das einzige Werkzeug, das das Mondfeuer bändigen kann — und Silvans [[Schattenlaterne]] ihr genaues Gegenstück.
