Story Forge — query engine mockups (M2)

Visual source of truth for the Dataview query engine, consent gate, import/bind modals, and settings rows. Rendered in the Obsidian dark-sidebar palette. Engine badges: dql = declarative, read-only; dataviewjs = arbitrary JavaScript, consent-gated.

Panel body states (S11–S18): use the M1 panel chrome (vhead + chead + tabs + body). The active tab is "Characters in Scene" (a DataviewJS or DQL view).   Modals (S19–S23): floating cards overlay a dimmed background.  Settings rows (S24–S26): the Manage Views list inside the plugin settings tab.
