Story Forge — Bases, Codex & catalog mockups (M4 / spec 005-bases-codex-catalog)

Main-area Codex / Overview grids (Bases registerBasesView), a bundled "Browse official" catalog with install + update + consent, a read-only .base sidepanel view-tab, and the minimal editable Inspector that proves the frontmatter write-back loop. Ships v0.2. Data is real, from test/StoryForge/ (Wardens of Moonharbor), verified against actual frontmatter.

Numbering: M3's highest S-number is S43 → M4 states start at S44. M4 reuses the M3 shell (.vhead / .chead / .tabs / .body, kind badges, sections). Codex / Overview are main-area surfaces (Bases registerBasesView) and are click-through browsers only; the sidepanel .base fence is read-only; the Inspector is the only editable surface — its commits write plain frontmatter (Story Forge never owns state). The Context tab defaults to the read-only M3 view; a pencil ✎ toggle beside the pin opens the Inspector and back (S58) — View and Edit share one visual language. ● not installed · ✓ installed · ⬆ update · ⚠ runs code · kind badges: characterlocationobjectloresceneplotline
