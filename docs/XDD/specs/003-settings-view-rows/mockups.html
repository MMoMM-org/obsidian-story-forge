Story Forge — Manage Views settings rows (mason card style)

Redesign of the plugin-settings Manage Views list to markdown-mason's Scripts-tab card aesthetic. Each imported view is a bordered card: primary line = name + provenance chip (Imported/Official) + kind pill (engine: dataviewjs/dql/bases) + a right-aligned status pill (icon + label) + a toggle + a single ⋯ menu; secondary line = description of what the view does.

Everything in one Views place. Enable/disable is the inline toggle; every verb — View source, Edit (rename tab label + assign command, the existing Edit modal), Re-review (on drift), Remove — is a ⋯ overflow-menu item, exactly like mason. Mason keeps command-assignment on a separate Commands tab; Story Forge folds it into the row's Edit so there is one place.   Colours: every hue maps to an Obsidian theme token (status = --text-success/-warning/-error, chips/pills via color-mix on themable hues) so rows are correct in light and dark themes; status never relies on colour alone (always icon + word).  Scope now: imported-only — the Official catalog / Import-from-repo is M4 (button shown disabled).  Command pill: a view that is also bound to a palette command shows a ⌘ command pill (driven by ViewRecord.command; its title is the command name). Toggle the binding in the row's Edit modal.
