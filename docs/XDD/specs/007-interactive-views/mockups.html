Story Forge — Interactive views mockups (M6 / spec 007)

Making the M5 read views interactive. M5 (spec 006) shipped the frontmatter-driven workspace surfaces (Navigator, Timeline rail, Plotlines list) as read-only. M6 adds direct manipulation that writes plain frontmatter back (per the founding frontmatter-is-truth decision — the plugin writes, Bases/the views render; the plugin never owns state) plus three new read-only spatial views. Every figure here is tagged M6.

M6 ships six features. Write-back (3): F1 Kanban (drag a card between status columns → writes status + re-sequences order), F2 Plotgrid (toggle a matrix cell → adds/removes a scene's plotlines link), F3 Timeline placement (drag a card to a new day → snaps storyDay to an integer, never touches order). Read-only (3): F4 Locations tree (nested world hierarchy), F5 Swimlanes (Timeline in lane mode, keyed by POV or plotline), F6 Zoom / pan (ephemeral timeline scaling). The Plotlines subway map stays M7.

Continues the M5 mockup numbering. M5 ran S59→S72; M6 continues at S73→S84. Visual language is unchanged — this file reuses the M5 <style> block verbatim and only extends it with interaction affordances (drag ghosts, drop lines, toasts, Kanban/Plotgrid/tree/zoom classes). The theme, status badges, and plotline palette are identical so the two spec files read as one. Ours vs StoryLine: StoryLine's board and grid mutate its own database; ours mutate plain frontmatter — every write is a value a human could have typed, and is fully reversible in the file.

Seed data (book Wardens of Moonharbor): scene 1 The Extinguished Fire (POV Mara Stoneway, Dying Light, draft, Night 1), 2 The Salty Gull (POV Mara, Dying Light, draft, Night 1), 3 The Black Cliffs (POV Mara, Dying Light, outline, Night 2), 4 The Signal Tower (POV Tobias Ferro, Warden's Oath, outline, Night 3), 5 A Message in Salt (POV Mara, Warden's Oath, outline, —), 6 The Long Watch (POV Elke Stoneway, no plotline → Unassigned, draft, Night 4). Plotlines: The Dying Light , The Warden's Oath , Shadow Trade (0 scenes), Unassigned . Locations nest under world: Moonharbor (root) → Moonharbor Lighthouse, The Salty Gull, Signal Tower.
