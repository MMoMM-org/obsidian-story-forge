Story Forge — Interactive views mockups (M6 / spec 007)

Making the M5 read views interactive. M5 (spec 006) shipped the frontmatter-driven workspace surfaces (Navigator, Timeline rail, Plotlines list) as read-only. M6 adds direct manipulation that writes plain frontmatter back (per the founding frontmatter-is-truth decision — the plugin writes, Bases/the views render; the plugin never owns state). Every figure here is tagged M6.

M6 ships two write surfaces and one rich read surface. Write-back (2): F1 Kanban (drag a card between status columns → writes status + re-sequences order), F2 Plotgrid (click/keyboard toggle a matrix cell → adds/removes a scene's plotlines link). Read-only: F5 Swimlanes (Timeline in columns-grid mode, keyed by POV/location/plotline), F6 Zoom (ephemeral CSS-scale on the rail; Ctrl+wheel also zooms). Timeline is strictly read-only — no placement drag. Removed from M6: F3 Timeline placement (deferred) and F4 Locations tree (moved to the Codex milestone). The Plotlines subway map stays M7.

Continues the M5 mockup numbering. M5 ran S59→S72; M6 continues at S73–S84 (original range) and adds S85–S89 for the reworked toolbar, swimlane grid, plotgrid, and drag ghost. Superseded figures (S77, S78, S79, S80) are kept with their original numbers and a superseded banner — the spec history stays readable. Visual language is unchanged — this file reuses the M5 <style> block verbatim and only extends it. Ours vs StoryLine: StoryLine's board and grid mutate its own database; ours mutate plain frontmatter — every write is a value a human could have typed, and is fully reversible in the file.
