# Phase 1: Schema foundation (plotline/book + image)

## Phase Context

**GATE**: Read all referenced files before starting this phase.

**Specification References**:
- `[ref: SDD/Building Block View/Data Storage Changes]` — new types + image fields
- `[ref: SDD/ADR-6]` (plotline+book first-class) · `[ref: SDD/ADR-7]` (image field)
- `[ref: PRD/F4]` — schema ACs
- `docs/schema-change-runbook.md` — ADD-a-type procedure
- `schema/scene.json`, `schema/character.json` — field-shape models

**Key Decisions**:
- `plotline`/`book` become first-class schema types generated by `schema:gen` (ADR-6).
- `book` needs a new `EntityKind` member + `TAG_MAP` row; `plotline` is already mapped.
- Optional `image` field on `object` + `location`, like `character.portrait` (ADR-7).
- Never hand-edit generated artifacts — edit `schema/*.json`, run `schema:gen`.

**Dependencies**: none (runs `[parallel: true]` with Phase 2).
