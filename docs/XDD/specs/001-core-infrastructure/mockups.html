Story Forge — panel mockups

Visual source of truth for the note-following panel. Rendered like the Obsidian right sidebar (dark theme). The Context tab body is a resolved-context view; in M1 it is a stub, M3 fills it with real content and the drill-in navigation (S10).

Follow (S1–S9): the panel’s subject = the active note.   Browse-in-panel (S10, M3): click an entity name to drill into it (subject changes, editor stays) — ↗ or ⌘-click opens the note instead. In a focused entity: ‹ back to the parent · name ▾ = other entities of the same category · ‹ pill › = switch category · 📌 pin freezes the subject. Dotted-underlined names are clickable (drill-in).
