Story Forge — Declarative workspace views (M5 / spec 006)

Two read-only, frontmatter-driven main-area workspace views: a linear Timeline (scenes by storyDay, fallback order, grouped by act, when as the label) and a Plotlines list (scenes grouped by plotlines, collapsible, "Unassigned" bucket). One polymorphic story-forge-workspace ItemView with a Timeline | Plotlines toggle. Data comes from a metadataCache scan — no Bases dependency (SDD ADR-1), so there is no Bases-off degrade. A scene click drills the M3 sidebar panel. Ships v0.3. Read-only (drag→frontmatter is M6).

Numbering: M4's highest S-number is S58 → M5 states start at S59. Reuses the M1–M4 shell (.vhead, collapsible .section, .lnk rows, kind badges, .emptybox). The earlier S63/S68 "Bases-off degrade" states are superseded by ADR-1 and re-purposed (S63 = "No act" bucket, S68 = unresolved-link group). Data is the (extended) seed — Wardens of Moonharbor, plotline The Dying Light (+ a second arc for multi-membership).
