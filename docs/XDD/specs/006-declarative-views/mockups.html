Story Forge — Declarative workspace views (M5 / spec 006)

StoryLine-grounded redesign. Three frontmatter-driven surfaces, all fed by a metadataCache scan (SDD ADR-1, no Bases). A compact Navigator is a third tab in the M3 sidebar leaf — a fixed tab alongside Context and the views-library tabs; the graphical Timeline and Plotlines are main-area views. Scene click drills the Context tab. Read-only in M5 (drag→frontmatter is M6).

M5 ships: Navigator + Timeline rail mode + Plotlines list mode. M6 adds: Timeline swimlanes (keys: POV, location, plotline — all three), Plotlines subway map, and drag→frontmatter. Views that support zoom/pan (subway, swimlane) must keep scene names clickable at every zoom level — implementation (SVG or DOM) is unconstrained.

Supersedes the earlier plain sectioned-list mockups. Visual language is modelled on the MIT-licensed obsidian-storyline plugin (Navigator, Timeline, Plotlines subway), rebuilt fresh on our frontmatter schema — no code port (per the founding frontmatter-is-truth decision). Colours, status badges, and the subway map are ours; StoryLine is a visual reference only, credited in NOTICE.

Seed data (book Wardens of Moonharbor, POV Mara Stoneway): 3 shipped scenes on plotline The Dying Light , plus the planned F0 extension (act-2 scenes, a second plotline The Warden's Oath , a multi-plotline scene, a no-plotline scene → Unassigned , a zero-scene plotline, and one unresolved link ) so swimlanes and lanes are meaningful. Status: draft · outline · written.
