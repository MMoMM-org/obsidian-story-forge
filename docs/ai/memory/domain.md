# Domain Memory

<!-- 2026-08-03 -->
- **`EntityKind` classification (tag→kind, ADR-4) has exactly one source of truth: `classifyEntityKind` in `src/scoping/NoteContext.ts`.** Spec-008 T4.3 originally shipped a second copy in `codex/cards/shared.ts` (unprefixed tags, since Cards only ever see `CardEntry.field("tags")`) — and it had already drifted from `ScopingService.classify`'s version: the Card copy had no frontmatter `type`-field fallback, so a note classifiable only via `type` read as `"unknown"` in one classifier and its real kind in the other, for the same note. Fixed in `d5f6cf2`: `classifyEntityKind(tags, type?)` is pure (no `App`) and lives in `NoteContext.ts`; `ScopingService.classify` strips metadataCache's `#` prefix before calling it, Card classification passes its already-unprefixed tags straight through. Don't re-duplicate this mapping for a new consumer — adapt to the pure function instead, even when the new consumer's tag vocabulary looks superficially different (prefixed vs unprefixed).
