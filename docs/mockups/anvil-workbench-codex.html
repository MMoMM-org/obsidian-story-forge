The two interfaces, drawn before any code. The surface model was settled on 2026-07-27 (DESIGN.md §2, gap-analysis.md §1.3): Anvil is the main-window interface, Workbench is the sidebar interface, and Codex is content that appears in both. These figures exist to test that model against a picture before it becomes code — per the repo rule, a mockup is a gate, not a record.

v3 — after review round 2. New: S102/S103 derive the editor's fields from the fc-*.md FileClass chain instead of a hardcoded list, which is what makes user properties first-class without an editor-styling system. Dock is manual only; every dock shows the full field set.
v2 — after review round 1. Figures are revised in place rather than superseded: v1 was a draft in review, never signed off, so a supersede chain would be noise. What changed: (1) the header slot no longer shows the source .base — it is the Card selector (S91, S97), because two independent axes had been collapsed into one label; (2) the editor pane gains close, fullscreen and a position toggle (S92, S99, S100); (3) S97 no longer swaps the data source — it swaps the Card, which is what makes it interesting; (4) S98's "Choose folders" became "Change tag", since selection is by tag; (5) new S101 shows the settings that make S93 and S97 possible.
Two axes, never one. The v1 draft wrote view: Codex.base (curated) in the header, which mixed what is shown with how it is drawn. They are independent:
Collection = what — Characters, Locations, Organizations. A query. Appears as the pill row; managed in settings (S101). Card = how — Hero, Table, Compact, or a user's own. Appears as the header dropdown; chosen per collection and remembered.
The word "view" is retired from the UI: it meant five different things. Codex.base already carries type: story-forge-codex per entry — the base supplies the query, our registered view type supplies the Card. The split exists in the code already; v1 only obscured it.

What v2 commits us to

If you sign this off, the following stop being open: (1) one Anvil view with a tab switcher, replacing four commands, tabs Codex · Timeline · Plotgrid · Plotlines · Board; (2) the Codex is a tab in Anvil, not a separate interface, and there is no third "note panel" surface; (3) Collection (what) and Card (how) are independent, both managed in settings, the Card remembered per collection — and "view" disappears from the UI; (4) the editor pane docks bottom or right, goes fullscreen, and closes; (5) the sidebar is called Workbench, command Open Workbench; (6) selection is by tag; folders only ever exclude, from settings; (7) the editor's fields, order, types, enum values and sections come from the FileClass chain — never from a hardcoded list — so a user's own fc-*.md is first-class without any editor-styling mechanism.
