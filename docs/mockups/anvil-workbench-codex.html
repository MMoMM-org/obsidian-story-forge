Story Forge — Anvil · Workbench · Codex (surface taxonomy)

The two interfaces, drawn before any code. The surface model was settled on 2026-07-27 (DESIGN.md §2, gap-analysis.md §1.3): Anvil is the main-window interface, Workbench is the sidebar interface, and Codex is content that appears in both. These figures exist to test that model against a picture before it becomes code — per the repo rule, a mockup is a gate, not a record.

What changes versus today. Four commands (open-timeline, open-plotlines, open-kanban, open-plotgrid) collapse into one Anvil view with a tab switcher; the Codex joins it as a first-class tab with a hero-card grid and an editor pane beneath; the sidebar gets a name and keeps the Codex as one of its tabs. Nothing about the existing Timeline, Plotgrid, Plotlines or Board rendering changes — only where they live and what they are called.

Continues the M6 numbering. M6 ran S73–S90; this set is S91–S98. Visual language is unchanged — this file reuses the M6 <style> block verbatim and only adds classes for the card grid, the editor pane and the Workbench body. Obligations differ per tab, not per interface: the Codex tab is substitutable (bring your own .base, see S97); the management tabs (Timeline, Plotgrid, Plotlines, Board) are deliberately opinionated — configurable, not user-authored. How a tab renders (Bases, Dataview, custom DOM) is an implementation detail and never a surface boundary. Amber callouts mark open questions that need your answer, not decisions already taken.
